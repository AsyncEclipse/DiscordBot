# Community Empires
Custom set of community empires

## Usage
Similar to the `community_parts` mod, this should be selectable when starting the game as a boolean input to the start game command. Doing so, will modify existing factions and add new factions.

## Eridani
Eridani will have the following changes

### Drafting minor species at the start of the game
The Eridani will have 2 additional slots on their player board specifically for drafting minor species. At the start of the game, the Eridani player will have the ability to draft up to 2 minor species and add them to these extra slots on their player board.
