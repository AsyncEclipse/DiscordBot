# Adding a community faction

Checklist from adding the Atlantians, excluding their custom abilities.

- **Faction data:** Add an entry in `data/factions.json` (`atl`): starting resources, population, technologies, action limits, tracks, ship costs, stock and blueprints. Match the existing fields.
- **Home sector:** Add the home tile in `data/sectors.json` (`266`, Atlantia), point `home_planet` to it, and add `images/resources/hexes/266.png`. Set population, wormholes and the coordinates used to draw pieces on the tile.
- **Selection:** In `Buttons/Draft.py`, add the faction to the draft only when `community_factions` is enabled, and give it a display colour in `getColor`. Add it to the setup command's faction choices in `commands/setup_commands.py`. Expose `community_factions: bool = False` during game creation and save it through `setup/GameInit.py`.
- **Colours:** New colours are not supported for now; each new faction must prefer one of the existing setup colours: blue, red, green, yellow, purple, white, pink, brown or teal (setup uses another available colour if the preferred one is taken).
- **Name lookups:** Map `Atlantians` to `atlantians` in both `GamestateHelper.getShortFactionNameFromFull` and `get_short_faction_name`, and in `DrawHelper.get_short_faction_name`. The data/command key (`atl`) and artwork key (`atlantians`) differ.
- **Artwork:** Under `images/resources/components/`, add `factions/atlantians_{board,info,ambassador}.png`, `layouts/factionImages/atlantians_image.png`, `layouts/faction_titles/name_trade_atlantians.png`, and `layouts/blueprints/classes/atlantians_{interceptor,cruiser,dreadnought,starbase}_class.png`. Send the board and reference from `commands/setup_commands.py`. In `DrawHelper.py`, turn-order portraits use the dedicated portrait without the crop used for existing faction boards.
- **Reputation slots:** The first two Atlantians slots hold reputation only. `Buttons/Reputation.py` must fill empty `rep` slots as well as `mixed` slots. Once filled, both contain numbers, so `PlayerHelper.is_reputation_only_slot` identifies them by position; diplomacy and minor species in `GamestateHelper.py` must preserve them, and `DrawHelper.py` must draw the correct slot backgrounds.
- **Checks:** Cover draft visibility and reference files (`tests/test_atlantians_faction_setup.py`), setup through a first round and artwork paths (`tests/test_atlantians_first_round.py`), reputation-slot preservation (`tests/test_atlantians_reputation.py`), and the abilities (`tests/test_ancient_spirit.py`, `tests/test_ancient_instinct.py`, `tests/test_discovery_part_power.py`). These tests check file loading, not visual quality; inspect the rendered board, portraits, blueprints and home tile too.
